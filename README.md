# Blue Tide 2027 Robot 🌊

**FRC Team 2840 · Phoenix Country Day School**

This repo is home base for the 2027 robot:

- **Issues** — every build task and robot problem, for all sub-teams (mechanical, software,
  electrical, CAD). Open one with a template: **[New issue](https://github.com/PCDSBlueTide/robot-2027/issues/new/choose)**.
- **Planning board** — all issues are tracked on the
  **[2027 Robot project](https://github.com/orgs/PCDSBlueTide/projects/2)** (team members).
- **Code** — robot code lands here at kickoff.

How the board works: [Planning Board guide](https://pcdsbluetide.github.io/2840-brain/handbook/planning-board) ·
Team handbook: [pcdsbluetide.github.io/2840-brain](https://pcdsbluetide.github.io/2840-brain/)
